# What leaves your machine

Nothing. LemonAId is one HTML file with no external scripts, stylesheets, fonts or network calls. Imported inventories, answers, notes and exports stay in the browser that opened the file and in the files you choose to save.

Browser storage is per browser and per file location. Export a session (JSON) to move your work; import it on the other side.

The public repository contains no project inventory and no personal data beyond the authors' names and two real validation fixtures from the Serrano Lab (a zebrafish flow experiment and a CUT&RUN run) that the authors chose to publish. Reagent names, clones and catalogue numbers come from the public EpiFlow Panel Builder.
